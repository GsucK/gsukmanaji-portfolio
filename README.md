# Portfolio Gunung Sukmanaji

Preview baru; website lama dan DNS gsukmanaji.com tidak diubah.

## Edit sendiri

1. Buka folder ini di VS Code atau Phoenix Code.
2. Buka `index.html`. Cari komentar `EDIT:` untuk hero, studi kasus, profil/Skills, approach, experience, dan kontak.
3. Edit teks di antara tag HTML, tanpa menghapus tag pembuka/penutupnya.
4. Simpan, lalu buka kembali `index.html` di Safari untuk melihat perubahan lokal.
5. `styles.css` mengatur tampilan; `script.js` hanya mengatur menu mobile dan status navigasi.
6. `resume.html` berisi ringkasan resume yang bisa dicetak menjadi PDF lewat tombol Print / Save as PDF.

Perubahan lokal tidak otomatis tampil di GitHub Pages; versi yang sudah disetujui harus dipush ke branch `main` repository `GsucK/gsukmanaji-portfolio`.
